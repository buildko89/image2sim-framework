## 1. 方式: 「塗り直す」のではなく「塗り替える」

素材の 4096² baseColor には、手描きの毛の流れ・陰影・目・鼻・肉球が描き込まれている。
これを捨てるとのっぺりしたビニール人形になる。そこで各テクセルの明度から
**局所的な陰影の比**を取り出し、その比を目標色に掛ける。

```
detail = (L + 25) / (blur(L) + 25)      # 局所シェーディング比
out    = target_color * detail          # 毛のディテールは残り、色だけ入れ替わる
```

目標色は `config/cat_color_palette_v3_raw_photos.yaml`（P0 で写真からWB補正して実測）。
柄の位置は `pipeline_v2/p3_uv_bake.py` が焼いた「テクセル → 3D位置・法線」から 3D の楕円体で定義する。

**素材の2枚のテクスチャは RGB がバイト単位で同一**（毛シェル用はアルファが付くだけ）と確認できたので、
1枚塗って両方に使い回す。毛シェル側だけアルファ付き PNG を割り当てる。

### 柄の定義（glTF系 X=左右 Y=上下 Z=前後, +Z=頭側。単位 m）

| 斑 | 中心 | 半径 | 色（実測） |
|---|---|---|---|
| 肩の丸い斑 | (-0.005, 0.185, +0.030) | (0.045, 0.068, 0.055) | ラスト中心 (95, 59, 31) |
| 左腰の斑 | (-0.050, 0.135, -0.112) | (0.034, 0.075, 0.058) | ラスト (118, 77, 44) |
| 右腰の斑 | (+0.050, 0.135, -0.112) | (0.034, 0.075, 0.058) | ラスト (118, 77, 44) |
| 尾根元の黒斑 | (0.000, 0.152, -0.116) | (0.032, 0.055, 0.050) | 黒 (45, 39, 33) |

体半幅は 0.067。**腰の斑は左右に分けて背骨を白く残す**（仕様の「背骨の中央が白く抜ける」）。
法線 Y による背側ゲートを掛け、腹には斑を置かない。

## 2. 踏んだ罠（4つとも実測で見つけた）

### (1) オレンジの毛を「ピンク」と誤検出して橙帯が残った

肉球・鼻を守るために `r>150 かつ r>g+25 かつ r>b+15` を使ったところ、
**ヒット画素の平均が (198,139,66) = オレンジの毛そのもの**だった。素材の橙帯が丸ごと保護され、
出力に元の柄が残った。

判定は **g−b** で行う。オレンジは g−b≈73、ピンクは g−b≈−9。
`r>140 かつ (r−g)>25 かつ (g−b)<20` に直すとヒットは 0.54%（肉球・鼻のみ、平均 (196,148,157)）。

### (2) 黒斑を体表の上空に置いていた

尾根元の黒斑を Y=0.180 に置いたが、臀部の背側表面は実測 **Y≈0.133〜0.157**。
斑の実効面積は **0.00%** だった。座標を測ってから置き直した。

### (3) 首を「頭」に分類していたので橙の染みが残った

顔を素材のまま残すために `part == HEAD` で保護していたが、`classify()` が
`bip01_neck` を頭に含めていた。首の付け根に素材のオレンジ帯が残り、
**どの方向から見ても染みに見えた。**

### (4) 顔をボーンで守ってはいけない

(3) を直して `HEAD = ["bip01_head"]` にしたら、**顔が真っ白になった。**
P1 のウェイト平滑化のせいで、顔のテクセルの支配ボーンは `bip01_head` ではなく
`bip01_neck` になっていた。

**保護範囲はスキニングに依存させず、3D座標で決める。**
`keep_head = smoothstep(0.095, 0.135, z)`（Z は前後方向）。滑らかなマスクなので境目も出ない。

### (5) 尻尾のリングが理髪店のポールになった

`sin` の硬い縞で上書きしたら、毛ではなく縞模様の筒になった。
素材の尻尾には毛のムラが描き込まれているので、**その明度を TAN↔BROWN のランプに写す**方式へ変更。
リングは位相を揺らした軽い変調（振幅 0.40）に留める。

```
ln   = 素材の明度を尻尾内で正規化
ring = 位相を揺らした sin
mix  = clip(0.70*(1-ln) + 0.40*ring - 0.12, 0, 1)
col  = TAN*(1-mix) + BROWN*mix
```

尻尾に沿った座標は、**尾根元からの3D距離**を使う。ボーン序数は `bone019/020` に
ウェイトが無いため t≤2 で頭打ちになり使えない。P2 で尻尾はほぼ直線（仰角 69〜78°）なので、
直線距離が弧長の良い近似になる。

## 4. 正直に残す点

- **尾根元の黒斑は、立てた尻尾にほとんど隠れる。** テクスチャ上には存在する
  （尾根元まわり |X|<0.025, Z∈[-0.14,-0.10] の背側テクセルの平均 RGB は (74,68,62)）。
  背面写真 `1755598074234.jpg` は尻尾が下りているので黒がよく見えるが、
  モデルは常時尻尾が立っているため見えにくい。**幾何の問題ではなく、ポーズの違い。**
- **胴の白がやや滑らかに見える。** 長毛感は毛シェル（`Koha9Tail`）のシルエットが担っており、
  胴の表面自体は 6,659頂点の低ポリ。ノーマルマップが素材に無いため、
  これ以上は毛シェルの押し出し量かノーマルマップの追加が要る。P3-2 の範囲。
- **顔は素材のまま。** koha の左右非対称なマスク（左頬の濃い焦茶、右頬の黒＋オレンジ混合）、
  額の黒い M、鼻筋のそばかすは再現していない。**P3-2 の範囲。**
- 肩の斑・腰の斑は左右対称に置いてある。実物は 1対1 対称ではない。P3-2 の範囲。

### 落とし穴（記録）

- **glTF の UV 原点は画像の左上。** Blender 流に `1-v` で反転すると、顔と尻尾が上下逆の場所に焼かれる。
- PIL の `GaussianBlur` は `mode="F"` を受け付けない。8bit に落としてから掛ける。
- 暗部（黒サドル、明度25前後）の `L/blur` は 8bit 量子化で相対ノイズが暴れる。
  そのまま白に掛けるとギラついた金属質の白になる。オフセット +25 を足して鈍らせる。
