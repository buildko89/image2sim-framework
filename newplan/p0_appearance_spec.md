## 2. 体型・比率

`横.png`（左側面・立位）にグリッドを重ねて読み取った。誤差は ±3% 程度。
**絶対寸法ではなく比率で扱う**こと。長毛のため輪郭は毛で膨らんでおり、骨格そのものではない。

体長 L = 鼻先 → 尾根元（側面投影）を 1.00 とする。

| 項目 | 値 | 補足 |
|---|---|---|
| 体長 L（鼻先→尾根元） | **1.00** | 基準 |
| 背の高さ（地面→背の最高点） | **0.64** | ±0.03 |
| 胴の厚み（背→腹の底） | **0.55** | 毛を含む |
| 腹の地上高 | **0.09** | 短足 + 豊富な腹毛。ほぼ地面すれすれ |
| 尻尾の立ち上がり（尾根元→先端の高さ） | **0.45** | 立てたとき先端は背より高い |
| 尻尾のプルーム最大径 | **0.18** | 胴の厚みの約 1/3 |

**要点は「短足」より「腹毛が地面に届く」こと。** 可視の脚は背の高さの 14% しかない。
現行モデルはこの比率で検証していないので、P1 完了後に同じ手順（側面レンダーにグリッド）で
計測し、本表と照合すること。

## 3. 毛

- **長毛。** 胸元に大きな飾り毛（ラフ）、後脚に飾り毛、尻尾に長いプルーム。
- 短毛のシルエットでは絶対に似ない。輪郭が毛でぼやけることが koha らしさの中核。
- 顔まわりは頬の毛が横に張り出し、輪郭が丸く見える。
- 素材 `koha9_cat` にはノーマルマップが無く、毛の陰影は baseColor に描き込まれているだけ
  （検証済み: 埋め込み画像は baseColor 2枚のみ）。長毛感は毛シェルの押し出し量で作る。

## 4. 柄の配置

### 全体

**白が優勢。** 胸・腹・脚・マズル・首まわりはすべて白。斑は背側と顔に限られる。

### 背面（`1755598074234.jpg` が最も明瞭）

- 肩に**丸いラスト色の斑**が1つ。背骨のやや左右どちらかに寄る。
- **尾根元に黒い斑。** 三毛の中で唯一まとまった黒の面。
- 黒斑を左右から挟むように、**両腰にラスト色の斑**。
- 背骨に沿った中央は白く抜ける。

### 側面

- 左右とも、肩と腰にラスト色の斑。斑の形と大きさは左右で異なる（1対1対称ではない）。
- 腹側は全面白。

### 顔

- マズル・顎・眉間のブレーズは白。
- 額に黒い「M」状の斑（眉間の白を挟む）。
- **猫の左頬**: 濃い焦茶の面マスクが耳の付け根から頬へ一枚に繋がる。
- **猫の右頬**: 黒とオレンジの混合。左ほど濃くない。
- 鼻筋にオレンジの小さな点（そばかす）が1つ。
- 目は緑。

### 脚

- 基本は白。
- 前脚・後脚の足首〜脛の外側に黒い斑が入ることがある（`1780491195055.jpg`、`横2.png` で確認）。
  ただし正面座位（`1763363798733.jpg`）では前肢はほぼ白一色に見える。
  **斑は脚の外側〜後面にあり、正面からは見えない**と解釈するのが写真と整合する。

### 尻尾

- 太いプルーム。**タン地に濃褐色のリングが並ぶ**（タビー柄）。
- 尾根元は体の斑と同じラスト色寄り。先端に向かうにつれてタンと濃褐色のコントラストが上がる。
- 先端は淡い。

## 5. 色（実測）

`pipeline_v2/p0_sample_palette.py` で、写真に写り込んだ白壁をホワイトバランス基準にして抽出。
枠の位置は `output_v2/reports/p0_palette_samples.png` で目視確認済み。

| 用途 | 中央値 RGB | 光の当たった面 (p85) | 出典 |
|---|---|---|---|
| 白（体） | (222, 219, 217) | (235, 231, 229) | 正面・胸 |
| 白（最も明るい・眉間） | (241, 238, 233) | (255, 252, 245) | 正面・ブレーズ |
| **ラスト（斑の中心・肩）** | **(95, 59, 31)** | (111, 74, 46) | 背面・肩 |
| ラスト（斑の標準・腰） | (118, 77, 44) | (128, 87, 56) | 背面・両腰 |
| **黒（顔のマスク）** | **(45, 39, 33)** | (56, 49, 43) | 正面・左頬 |
| 尻尾 タン | (173, 144, 118) | (184, 156, 129) | 正面・尻尾 |
| 尻尾 濃褐色 | (76, 61, 50) | (101, 84, 71) | 正面・尻尾 |
| 尻尾 尾根元の橙み | (127, 90, 56) | (145, 108, 73) | 正面・尻尾 |
| 鼻筋のそばかす | (158, 123, 102) | (186, 162, 150) | 正面・鼻 |

### 色についての注意（重要）

1. **koha のオレンジは「明るい橙」ではなく「深いラスト（錆色）」。** 中央値で (95〜118, 59〜77, 31〜45)。
   白 (222) との明度差が非常に大きい。ここを明るいオレンジにすると別の猫になる。
2. **黒斑は背面写真では影で (6,6,4) まで潰れる。** ベースカラーにそのまま使ってはいけない。
   採光の良い正面写真の顔マスク **(45, 39, 33)**（わずかに暖色寄りの黒）を黒の代表値とする。
3. **顔のオレンジ（頬・額）は影で沈み (55,47,44) 程度にしかならない。** 面積色の抽出には使えない。
4. 中央値は毛の谷間の影を含む。ベースカラーには中央値、ハイライトの当たりを確認するときは p85 を見る。

### 既存パレットの扱い

`config/cat_color_palette.yaml` は**破棄する。** 全6色が `source: koha_render_b3v2`、すなわち
素材アセットの宣材レンダー由来であり、実物の写真から取られていない。
新しい実測値は `config/cat_color_palette_v3_raw_photos.yaml`。

## 6. 素材アセットとの差分（P3 で埋めるべきもの）

`input/cat2/koha9_cat` のテクスチャ `Koha9Body_baseColor.png` と koha の主な違い。

| 項目 | 素材アセット | koha（実物） |
|---|---|---|
| 黒の面積 | **背中の大半が黒いサドル** | 尾根元と顔のマスクのみ。ごく小さい |
| 白の面積 | 腹側と脚のみ | 圧倒的に優勢。背骨の中央も白く抜ける |
| オレンジ | 背の上部に帯状 | 肩と両腰に独立した斑 |
| 尻尾 | 濃褐色主体 | タン地に濃褐色のリング |

**P3-1 の核心は「背中の黒いサドルを削って白に戻し、肩と腰にラスト色の斑を置くこと」。**

## 7. 合否チェックリスト

### P3-1「印象合わせ」の合格条件（これで完成とみなす）

- [ ] 白が優勢に見える。特に**背骨の中央が白く抜けている**。
- [ ] 斑の色が明るい橙ではなく**深いラスト色**である。
- [ ] **黒が少ない。** 背中に黒いサドルが無い。黒は尾根元と顔だけ。
- [ ] 尻尾が**太いプルーム**で、タン地に濃褐色のリングが入る。
- [ ] 長毛に見える。胸元の飾り毛がある。
- [ ] 腹毛が地面近くまで垂れ、脚が短く見える。

### P3-2「位置合わせ」の合格条件（余力があれば）

- [ ] 肩の丸い斑が1つ、背骨寄りにある。
- [ ] 尾根元の黒斑を、両腰のラスト斑が左右から挟む。
- [ ] 顔の左頬が濃い焦茶の面マスク、右頬が黒＋オレンジの混合になっている（左右非対称）。
- [ ] 額に黒い M 状の斑と、眉間の白いブレーズがある。
- [ ] 鼻筋にオレンジのそばかすが1つある。

### 全フェーズ共通（機械ゲート）

- [ ] `python pipeline_v2/qa_skin_stretch.py --glb <出力GLB>` が **OVERALL: PASS**
