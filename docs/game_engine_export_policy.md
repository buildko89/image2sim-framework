# ゲームエンジン向けエクスポート方針

## 対象

- Godot
- Unity
- Unreal

## 基本方針

- BlenderをMVPの中心ツールにする。
- モデルの足元または接地点を `Z=0` に合わせる。
- モデル中心を原点付近に置く。
- 単位はメートル基準にする。
- 不要な参照画像、image empty、作業用オブジェクトは本番エクスポート前に削除する。
- GLBを標準確認形式にする。
- FBXをUnity / Unreal向けの互換形式として併用する。

## Blender正規化

Task 4の標準処理:

- アセットを読み込む。
- メートル単位に設定する。
- 必要に応じて参照オブジェクトを削除する。
- X/Y方向の中心を原点に寄せる。
- 最下点を `Z=0` に合わせる。
- 指定した目標高さへスケールする。
- 必要に応じてスケール変換を適用する。
- GLBとFBXを出力する。

## Godot

- まずGLBで確認する。
- GodotではGLBをプロジェクトに配置し、シーンへインスタンス化して表示確認する。
- 最初の表示確認はGodotを優先してよい。

## Unity

- GLBまたはFBXを `Assets/` 配下に配置する。
- FBXでは `-Z Forward` / `Y Up` を基準にする。
- スケールと足元原点をUnity上で確認する。

## Unreal

- FBXまたはGLBをContent Browserからインポートする。
- インポート後、床面との接地、スケール、向きを確認する。
- 必要ならUnreal側のimport設定ではなくBlender側で再正規化する。
