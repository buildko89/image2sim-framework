# ドローンモデル生成のテンプレート方式

## 1. 結論

既存のdrone2用4ロータX型生成を残したまま、機体ごとの差分設定で別のマルチロータ機を作れる構成へ拡張した。

この方式はローカル3D生成AIを使用しない。写真と実測寸法を人またはCodexが読み取り、YAMLへ記録し、共通Python処理がBlenderをバックグラウンド実行して `.blend` と `.glb` を生成する。

「任意のドローン」とは、現在の部品ライブラリで表現できるマルチロータ機を、ローター数・配置・寸法・部品有無の組合せで作れるという意味である。写真だけから未知の複雑な外形を自動復元するものではない。新しい特徴的部品が必要な場合は、その部品のBlender生成関数を追加する。

## 2. ファイル構成

| 種別 | ファイル | 役割 |
|---|---|---|
| 実行入口 | `scripts/drone_model/run_build.py` | テンプレート継承、配置計算、QA、Blender実行 |
| Blender生成 | `blender/drone_model/build_drone.py` | ボディ、アーム、モーター、ローター、ガード、脚部、衝突形状の生成 |
| 既存4ロータ互換 | `config/drone_templates/quad_x_guarded.yaml` | 4ロータX型・ガード付きの標準値 |
| 汎用基礎 | `config/drone_templates/multirotor_base.yaml` | 可変ローター数モデルの標準値 |
| drone2固有設定 | `config/drone2_model.yaml` | 実測値、写真、drone2固有寸法、出力先 |
| 6ロータ例 | `config/examples/hex6_radial_model.yaml` | 放射状6ロータ構成の動作確認例 |
| 回帰テスト | `tests/test_drone_model_templates.py` | 継承と3種類の配置計算を検査 |

## 3. 継承の考え方

機体固有設定の先頭でテンプレートを指定する。

```yaml
template_file: config/drone_templates/multirotor_base.yaml
subject_id: new_drone
```

テンプレートの値を基礎とし、機体固有設定に書いた値だけを再帰的に上書きする。例えば次の設定では、テンプレート内のボディ高さなどは維持し、幅だけを55 mmへ変更する。

```yaml
body:
  width_mm: 55.0
```

実行時の最終設定は、各出力ディレクトリの `resolved_config.json` へ保存される。値がどちらから来たかを確認するときは、このファイルを使う。

## 4. 対応するローター配置

### 4.1 対角寸法から作る4ロータX型

既存drone2が使用する互換方式である。ローターIDは `fl`、`fr`、`rl`、`rr` のまま維持される。

```yaml
layout:
  mode: square_diagonal
  motor_axis_z_mm: 7.0

measurements:
  motor_center_diagonal_mm:
    value: 95.0
```

### 4.2 同一半径へ等間隔に置く放射配置

3、4、6、8ロータなど、中心から同じ距離へ等間隔に配置する機体に使う。

```yaml
layout:
  mode: radial
  rotor_count: 6
  radius_mm: 55.0
  start_angle_deg: -90.0
  id_prefix: r
  motor_axis_z_mm: 5.0
```

この例では `r1` から `r6` までの部品、ローター軸、衝突形状が自動生成される。

### 4.3 各モーターを個別指定する配置

前後非対称、三角形、同軸配置の準備など、等間隔でない機体に使う。値は `[X, Y, Z]` mmであり、Zを省略した場合は `motor_axis_z_mm` を使う。

```yaml
layout:
  mode: explicit
  motor_axis_z_mm: 6.0
  motor_positions_mm:
    front: [0.0, -48.0]
    rear_left: [-42.0, 35.0, 7.0]
    rear_right: [42.0, 35.0, 7.0]
```

## 5. 切替可能な構成

現在は次を設定から変更できる。

- ローター数と各ローターID
- モーターの配置と高さ
- ローター回転方向の個別指定、または `direction_pattern` の繰返し
- プロペラ径、羽根数、羽根幅、厚さ、ハブ寸法
- ボディ寸法と `lofted`、`rounded_box` の2形状
- アームの有無、太さ、厚さ、接続開始位置
- プロペラガードの有無、外径、断面、開口、支柱数
- 脚部の有無と寸法
- 重心アンカー、ローター軸アンカー、単純衝突形状

ガード外径には次の2方式がある。

- `fit_overall`：実測した機体全幅・全長とモーター配置から外径を計算する。
- `explicit`：`guard.outer_diameter_mm` を直接指定する。

## 6. 新しい機体を作る手順

1. 上、下、前、後、左、右の写真を用意する。
2. 全幅、全長、ボディ幅・長さ・高さ、モーター中心位置、プロペラ径を測る。
3. 最も近いテンプレートを選び、`config/examples` の例を複製して機体固有設定を作る。
4. `layout.mode` と寸法を入力する。
5. Blender生成を実行する。
6. 6方向レンダーと実物写真を比較し、仮置き寸法を更新する。
7. 質量、重心、慣性を実測し、シミュレーション用物理値を追加する。

実行例：

```powershell
python scripts\drone_model\run_build.py --config config\examples\hex6_radial_model.yaml --overwrite --skip-contact-sheet
```

参照写真を `top`、`bottom`、`front`、`back`、`left`、`right` の6方向すべて指定した場合は、`--skip-contact-sheet` を外すことで比較シートも生成できる。

## 7. 既存drone2の互換性

既存コマンドは変更していない。

```powershell
python scripts\drone_model\run_build.py --overwrite
```

テンプレート化後の回帰生成結果は次のとおりである。

| 確認項目 | 結果 |
|---|---:|
| ローター数 | 4 |
| 全幅 | 132.989973 mm |
| 全長 | 132.989973 mm |
| ボディ幅 | 34.000000 mm |
| ボディ長 | 50.000001 mm |
| ボディ高 | 25.000000 mm |
| 必須部品名の欠落 | 0 |
| QA | PASS |

プロペラは従来どおり `rotor_fl` などの独立ノードを持つため、BlenderやGLB読込先で個別回転できる。

## 8. 6ロータ実証結果

`hex6_radial_model.yaml` から、既存drone2とは別の出力先へ6ロータモデルを生成した。

| 確認項目 | 結果 |
|---|---:|
| 配置 | radial |
| ローター数 | 6 |
| ボディ寸法 | 42 × 60 × 18 mm |
| プロペラガード | なし |
| 脚部 | なし |
| 必須部品名の欠落 | 0 |
| QA | PASS |

成果物は `output/template_smoke/hex6_radial` にある。これにより、共通処理が4ロータ固定ではないことを確認した。

## 9. 現時点の限界と次の拡張候補

- 一体成形された複雑な外殻、ダクト、カメラジンバル、折り畳み機構は専用部品関数が必要である。
- 上下同軸ローターは個別位置を置けるが、同軸機専用のアーム接続や干渉検査は未実装である。
- 写真輪郭の自動トレースは未実装で、現状は寸法と目視比較で調整する。
- GLBに回転アニメーションは埋め込んでいない。独立ローターノードを利用して、シミュレータ側またはBlender側で回転させる。
- 質量、重心、慣性、推力係数は形状から確定できないため、実測または別途同定が必要である。

次に実機写真から別機体を作る場合は、まず `explicit` 配置で各モーター中心を入力し、既存2種類のボディ形状で近似できるかを判定する。近似できない特徴だけを新しい部品テンプレートとして追加する進め方が安全である。
