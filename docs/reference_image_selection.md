# 見た目基準画像の選定

## 目的

Task 3F以降で、リグ付きベースモデルを猫らしい見た目へ寄せるために使う基準画像を選定する。

対象は次の2か所。

- `input/raw_photos/`
- `input/raw_photos/video_frames/`

## 選定方針

- 高解像度の静止画を主基準にする。
- 動画フレームは、静止画で不足する角度や低い目線の補助として使う。
- 写真としてきれいかよりも、体型、毛色、模様、尻尾、顔の判断に使えるかを優先する。
- 背景除去や3D生成に直接使うかは別判断とする。

## 選定した画像

### 主基準

#### 1. 横向き・体型・胴体模様

- 元画像: `input/raw_photos/1698975320501.jpg`

## 採用しなかった候補の傾向

- 顔が近すぎて全身が分からない画像。
- 体の一部が大きく隠れている画像。
- 似たフレームが連続しており情報量が重複する画像。
- 背景や家具が目立ち、輪郭確認に使いにくい画像。
- ブレや暗さで毛色判断が難しい画像。
