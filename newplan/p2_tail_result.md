# P2: 尻尾 — 実行結果

> **完了:** 2026-07-10

> **再現:** `python pipeline_v2/p2_run.py`（再バインド → 尻尾カール → リターゲット → 機械ゲート）

## 1. 方式

**頂点を一切触らない。尻尾ボーンを回してポーズを作り、それを `Apply as Rest Pose` でレストに焼く。**
メッシュはスキニングで自動的に追従する。

B-6 は尻尾メッシュの頂点を155°の累積カーブで直接曲げていた（`curl_tail_mesh`）。
その結果、背面から見るとトゲ状に破綻した（`png/test/back.png`）。その関数はもう使わない。

### 実行順序（厳守）

```
再バインド（尻尾はまっすぐ） → 尻尾カール → アニメーションのリターゲット
```

- **束縛前にカールしてはいけない。** 巻き上げた尻尾は背中の直上を通るので、ボーンヒートが
  背中の頂点を尻尾ボーンに吸わせる。
- **リターゲット後にカールしてはいけない。** 尻尾の回転キーが二重に効く。
  `b6b_retarget_animations_blender.py` は「尻尾の元キーはカール済みレストへの相対適用が正しい」
  前提で書かれている（B-6 の設計どおり）。

`bake_pose_to_rest()` では、Armature モディファイアの**複製を1つ適用**してメッシュ形状を
確定させてから `pose.armature_apply()` する。これをやらないとメッシュだけ元に戻る。

## 2. 回転軸の決め方

尻尾ボーンは roll のせいで**ローカル Z がほぼワールド −X を向く**（`p2_inspect_tail_blender.py` で実測）。
「ローカル X 回りがピッチ」という常識が通用しない。

そこで軸を決め打ちせず、**ワールド X 軸（左右軸）まわりの回転をボーンのレスト基底に共役変換**して適用する。

```python
world_rot = Matrix.Rotation(radians(deg), 3, "X")
rest      = pb.bone.matrix_local.to_3x3()
basis     = rest.inverted() @ world_rot @ rest
```

符号は実測で決める（+1 を試し、先端が下がったら −1 でやり直す）。実行結果は `sign=+1`。

## 3. 角度は写真から読んだ

`input/raw_photos/横.png` にグリッドを重ねて尻尾の各区間の傾きを読むと、
**根元から先端までほぼ 65〜78°（水平から）で、ほぼ直線**だった。バナナ状には曲がらない。

### 失敗した1回目: 累積角の配分方式（total 125°、根元ほど重み大）

| | bone016 | bone017 | bone018 | bone019 | bone020 |
|---|---|---|---|---|---|
| 仰角（結果） | 41° | 59° | 80° | 91° | 118° |

根元が寝て先端が前へ行き過ぎ、S字に膨らんだ。写真と並べると一目で違う。

### 採用: ボーンごとのデルタ角を直接指定

レスト仰角が `-11.1, -23.5, -22.5, -24.4, -6.8` 度なので、
最終仰角が 70° 前後になるようデルタを逆算した。

**`--bone-deg 81,12,0,2,-10`**

| | bone016 | bone017 | bone018 | bone019 | bone020 |
|---|---|---|---|---|---|
| デルタ角 | +81° | +12° | 0° | +2° | −10° |
| 仰角（結果） | **69.6°** | **68.9°** | **69.8°** | **69.8°** | **77.7°** |

**根元をほぼ全部曲げ、以降は軸をまっすぐ保ち、先端だけ少し戻す。** 猫が尻尾を立てるときの
実際の形（根元の曲げ + まっすぐな軸）と一致する。

## 5. ゲート

### 機械ゲート: `OVERALL: PASS`（全8アニメ）

| アニメ | 破綻辺 | | アニメ | 破綻辺 |
|---|---|---|---|---|
| Idle1 | 0.044% | | Atk2 | 0.188% |
| Walkback | 0.120% | | Run | 0.364% |
| Walk | 0.128% | | Jump | **0.453%** |
| Atk1 | 0.140% | | Idle2 | 0.180% |

カールで Jump が 0.356% → 0.453% に悪化した（`bone016` が尾根元の胴側頂点を引っ張る）。
閾値 0.5% 内だが**最も余裕が無い**。P4 で尻尾の振りを抑えるなら合わせて改善したい。

毛シェル（`Koha9Tail`）の破綻は **4頂点 / 1,719（0.23%）**。カールで毛カードは壊れていない。

### 目視ゲート

- 写真との比較: `output_v2/reports/p2_tail_vs_photo.png`
- 4方向×8アニメ: `output_v2/reports/p1_contact_p2_overview.png`

全8アニメ・4方向で破片・欠損・貫通なし。尻尾のシルエットは `横.png` とよく一致する。

**背面から見ると尻尾が黒いトゲ状の束に見えるが、これは幾何の破綻ではない。**
アルファの毛カード（`alphaMode: BLEND`、1枚19頂点）を真後ろから見たフリンジであり、
素材の尻尾テクスチャが濃褐色なのでそう見える。koha の尻尾はタン地に濃褐色のリングなので、
**P3 でテクスチャを差し替えれば印象は変わる。**
