# Task 71.5: 不足アニメーション（ネコパンチ、起き上がり/威嚇）の追加（完了）

ドローンシミュレータのユースケース（「眠っている状態」からドローンの接近を検知して「起き上がり・威嚇」を行い、至近距離で「ネコパンチ」を放つ）を満たすため、プログラムを介したキーフレーム設定により新規カスタムアニメーションを追加しました。

---

## 1. 実施内容

Blender 5.0 Python API を使用し、[cat_deformed.blend](file:///D:/source/repos/3DModelDevPJ/image2sim-framework/output/rigged/cat_deformed.blend) の骨格（`CatGirl2:` プレフィックスの54ボーン）に対してキーフレームを挿入しました。

### ① 新規追加したアニメーション
1. **`Cat_Punch` (ネコパンチ - 30フレーム):**
   - **0〜5F:** 右前足（`frontHip_R`, `frontKnee_R`）を後方・内側に引き、パンチのための「タメ」を形成。
   - **5〜10F:** 肩と肘を大きく前上方に回転させ、右前足を高く振り上げる。頭（`Head_M`）も少し右足方向へ傾ける。
   - **10〜14F:** インパクト。勢いよく前足を前下方に振り下ろし、肘を伸ばすストレート打撃。
   - **14〜30F:** ゆっくりと元の立ち待機ポーズ（`Cat_Idle`）へと戻す。
2. **`Cat_WakeUp` (起き上がり/威嚇 - 60フレーム):**
   - **0〜15F:** `Cat_Sleep` の丸まって寝ているポーズを維持。
   - **15〜20F:** 頭と首（`Neck_M`）をゆっくり持ち上げ、周囲を警戒する動作。
   - **20〜30F:** 前足を踏ん張って上体を起こす。
   - **30〜40F:** 立ち上がると同時に背中（`BackA_M`）を上に25度、腰を15度丸め、首をすくめて顎を引く**「威嚇ポーズ（ハンプバック）」**を表現。
   - **40〜45F:** 威嚇姿勢を維持。
   - **45〜60F:** 自然な立ち待機ポーズ（`Cat_Idle`）に遷移。
