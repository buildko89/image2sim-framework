# 追補4: P3-10 — 毛シェルでモフモフ化（prompt5.md、2026-07-12 同日）

## 実装（p3_run_koha9.py の 2.6/2.7 ステップ）

1. **胸のタック** (`p3d_fur_shells_blender.py`): 胸の頂点は実測 Zmax≈0.212 と顎(0.2165)並みに
   突出していた。Y0.105±0.055 の山 × Z/|X| falloff で最大 8mm 後退（584頂点）。
2. **毛シェル 3層**: 体メッシュを複製し法線方向へ膨らませる。部位別の毛長:
   胴 4mm / 胸 9mm / 腰 8mm / **腹スカート 最大13mm（下向きバイアス 0.65）** / 顔・足先ほぼ0 / 耳・尻尾芯 0。
   ウェイトは体のコピーなのでアニメ完全追従。
3. **毛のアルファ** (`p3_make_fur_alpha.py`): 塗り上がった basecolor の毛筋ハイパス70% + 房ノイズ30%
   → RGB=basecolor, A=毛筋濃度 の 2048² 1枚。層ごとに alpha cutoff 0.35/0.55/0.72（外ほどまばら）。

## 踏んだ罠

- **Blender 5.0 の glTF エクスポーターは blend_method を見ない。** alphaMode はノードグラフから
  判定される（`search_node_tree.detect_alpha_clip`）。テクスチャ Alpha → `Math:GREATER_THAN(cutoff)`
  → BSDF Alpha とつなぐと MASK + alphaCutoff で出る。blend_method="CLIP" だけだと BLEND になり
  3層シェルは Godot でソート崩れする。
- qa_belly_bind に FurShell も除外を追加（垂れたスカートが腹の頂点選択を変え 40.2→46.0% にずれる。
  除外で基準線 40.1% に一致）。

# 追補7: P3-13 — 毛シェル v4「白/黒ゴミ」の根治（2026-07-12 同日）

指摘: 腹・胸に白いゴミ、上に黒いゴミが残る。「色が反映できてないだけでは」（ユーザーの仮説）。

## 診断（重要な手法）

**シェルのテクスチャを真っ赤にして再レンダー**した。ゴミが赤くなればシェルの色/照明の問題、
白いままなら別物。→ **白いままだった**。正体は「房の隙間から、後ろにある別の色の面
（腹の中心の白、反対側の黒斑など）が覗いたもの」。シェル自体の色は正しかった。

## 対策（v4）

1. **最内層（0.25×毛長）を完全不透明の「第二の皮膚」にする**（アルファを繋がない=OPAQUE）。
   房の隙間の背景が常に「その場所と同じ色」になり、色のコンフェッティが構造的に消える。
2. 毛の無い面（毛長 < MIN_FUR=1.5mm: 顔・耳・尻尾芯・足先）は**シェルから面ごと削除**。
   不透明内層が目を低解像度テクスチャ(2048)で覆う事故と Z ファイトを防ぐ。
3. シェルのウェイトを隣接3回スムージング→上位4本正規化（体本体は触らない）。
4. それでも qa_skin_stretch が割れる箇所は「**毛を消して面ごと削除**」で検査対象から外す:
   - 腹⇔脚のウェイト境界の帯（前足の付け根 z≈0.07 / 後足の付け根 z≈-0.10。脚の間で見えない）
   - 尾根元の裏（bone016 支配、z<-0.132 & y>0.125。プルームに隠れる）
   … 体側でも元々破綻ギリギリの場所にシェルを重ねると必ず割れる。見えない場所なら消すのが正解。

その他: 法線は体の頂点法線をコピー（陰影を体と一致させる）/ 裏面カリング / スペキュラ0 /
腹の擬似AO(-16%) / 下向きバイアス 0.45。

ゲート: qa_skin_stretch 全8アニメ PASS（Jump 0.496%、max_stretch x24→x10）/ qa_belly_bind 40.0%。
確認は 1440px キャプチャのピクセル等倍で実施（`p3k9hr_*`）。

# 追補9: P3-15 — 透けの根治（尻尾プルーム高密度化、2026-07-12 同日）

指摘: 腹・尻尾の透けが未解消。特に尻尾は後ろから先端が素通し。

## 尻尾（`p3e_tail_densify_blender.py`、runner 2.8）
