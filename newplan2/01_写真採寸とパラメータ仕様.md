# 写真採寸とパラメータ仕様

## 1. 目的

6方向写真と実測値から、Blender部品生成へ渡す寸法設定を作る。
ここで作る設定値をモデルの正とし、Blenderファイル内で直接変更した値は正としない。

## 2. 情報源の優先順位

寸法の採用順位は次のとおりとする。

1. 手元の実物をノギス、定規、はかりで測った値
2. 同一製品・同一型番の公式寸法
3. 複数写真から得た比率を実測基準値へ換算した値
4. 構造上の対称性や部品関係から計算した値
5. 写真で隠れている箇所の仮置き値

外部の製品仕様と写真から求めた寸法が違う場合は、手元の実物を優先する。
プロペラ、ガード、外装などが交換されている可能性も考慮する。

## 3. 寸法の確度区分

各値に`source`と`confidence`を持たせる。

| source | 意味 | 初期許容差の目安 |
|---|---|---:|
| `measured` | 実物を直接測定 | ±0.5～1.0 mm |
| `specification` | 公式仕様 | 仕様記載値に従う |
| `photo_estimated` | 写真比率から推定 | ±2 mmまたは±3%の大きい方 |
| `derived` | 他の確定値から計算 | 元の値の誤差を継承 |
| `placeholder` | 見えない箇所の仮置き | ±5 mmまたは±10%の大きい方 |

初期値であり、写真の傾きや透視が強い場合は許容差を広げる。

## 4. 最低限必要な基準寸法

写真だけでは絶対スケールを決められないため、次から1個以上を実測する。

| 優先度 | パラメータ | 測り方 |
|---:|---|---|
| 1 | `motor_center_diagonal_mm` | 対角にある2個のモーター軸中心間 |
| 2 | `motor_center_x_mm` | 左右モーター軸中心間 |
| 3 | `propeller_diameter_mm` | プロペラ先端から反対側先端まで |
| 4 | `guard_outer_diameter_mm` | ガード外周の直径 |
| 5 | `overall_width_mm` | 左右の最外形間 |

中心間距離は外装端より写真上の対応点を取りやすく、基準値に向いている。

## 5. 写真ごとの用途

| 写真 | 主に読む寸法・形状 | 注意点 |
|---|---|---|
| 上 | モーター中心、ガード外径、全幅、全長、中央ボディ平面形 | 高さ方向は読めない |
| 下 | アーム接続、下面外装、電池部、ガード支柱 | 上面と隠れ方が異なる |
| 前 | 全高、左右モーター高さ、中央ボディ幅、脚・下面 | 奥行きは透視の影響が大きい |
| 後 | 後面外装、LED・端子、左右高さ差 | 前写真との倍率差を補正する |
| 左 | 全長、全高、前後モーター位置、外装側面 | 左右写真で傾きを相互確認する |
| 右 | 全長、全高、前後モーター位置、外装側面 | 左写真と独立した倍率を持たせる |

上面と下面、左面と右面、前面と後面で一致しない値は平均しない。写真の傾き、
隠れ、部品の非対称性を確認し、どの値を採用したか記録する。

## 6. 画像座標から寸法への換算

### 6.1 基本式

同じ写真上で既知長を`R_mm`、その画素長を`R_px`、測りたい画素長を`L_px`とすると、
正投影近似で次の値を得る。

```text
L_mm = L_px × R_mm / R_px
```

この式は、2本の線分がカメラからほぼ同じ奥行きにある場合に限って使う。
前後方向に離れた部品を同じ尺度で測ると透視誤差が入る。

### 6.2 写真補正

各写真について次を保存する。

- 元画像サイズ
- 使用する切抜きまたはマスク
- 基準となる2点の画像座標
- 機体中心の画像座標
- 画像内の機体回転角
- Blender参照カメラの平行移動
- Blender参照カメラの倍率または焦点距離
- 上下左右の反転有無
- 補正者と更新理由

最初は正投影カメラで合わせる。正投影で前後の輪郭を同時に合わせられない場合だけ、
透視カメラと焦点距離推定へ進む。初期段階でレンズ歪み推定まで広げない。

### 6.3 ランドマーク

各写真で、次の特徴点を人が確認して保存する。

```text
body_center
motor_fl_center
motor_fr_center
motor_rl_center
motor_rr_center
body_front_tip
body_rear_tip
body_left_edge
body_right_edge
body_top_edge
body_bottom_edge
```

`fl`はfront-left、`fr`はfront-right、`rl`はrear-left、`rr`はrear-rightを表す。
前方向はBlender座標の`-Y`とする。

ランドマークはAI検出しない。初期実装では画像ビューアまたはBlender上で人が選び、
ピクセル座標を設定へ保存する。輪郭抽出を補助に使う場合も、採用点は人が確認する。

## 7. モデル設定の構成

推奨ファイル：`config/drone2_model.yaml`

```yaml
schema_version: "1.0"
subject_id: drone2_petron_s
units: mm
coordinate_system:
  right_axis: +X
  front_axis: -Y
  up_axis: +Z
  root_origin: estimated_center_of_mass

measurements:
  motor_center_diagonal_mm:
    value: null
    source: measured
    tolerance_mm: 1.0
    note: 最初に実測する必須値
  overall_width_mm:
    value: null
    source: photo_estimated
    tolerance_mm: 2.0
  overall_length_mm:
    value: null
    source: photo_estimated
    tolerance_mm: 2.0
  overall_height_mm:
    value: null
    source: photo_estimated
    tolerance_mm: 2.0
  mass_g:
    value: null
    source: measured
    tolerance_g: 1.0

body:
  width_mm: null
  length_mm: null
  height_mm: null
  corner_radius_mm: null
  top_dome_height_mm: null
  bottom_depth_mm: null

arm:
  root_width_mm: null
  tip_width_mm: null
  thickness_mm: null
  root_height_mm: null
  motor_height_mm: null

motor:
  housing_diameter_mm: null
  housing_height_mm: null
  shaft_radius_mm: null
  shaft_height_mm: null

propeller:
  diameter_mm: null
  hub_diameter_mm: null
  hub_height_mm: null
  blade_count: 2
  blade_root_width_mm: null
  blade_tip_width_mm: null
  blade_thickness_mm: null
  pitch_deg: null

guard:
  outer_diameter_mm: null
  tube_diameter_mm: null
  height_mm: null
  strut_width_mm: null

physics:
  center_of_mass_mm: [0.0, 0.0, 0.0]
  mass_g: null
  inertia_kg_m2: null
  inertia_source: pending
```

`null`の項目は未確定を意味する。ビルド時に必須値が`null`なら、正規GLBの生成を
失敗させる。Blockoutモードだけは仮置き値を許可し、成果物へ
`dimensions_provisional=true`を記録する。

## 8. 派生値

4個のモーター中心が正方形配置で、対角中心間距離を`D`とする場合、左右および
前後の中心間距離`S`は次で求められる。

```text
S = D / √2
```

ただし、写真で長方形配置または前後オフセットが確認できる場合は、正方形を仮定せず、
`motor_center_x_mm`と`motor_center_y_mm`を別々に設定する。

モーター位置は次を基本形とする。

```text
FL = (-Sx/2, -Sy/2, Zmotor)
FR = (+Sx/2, -Sy/2, Zmotor)
RL = (-Sx/2, +Sy/2, Zmotor)
RR = (+Sx/2, +Sy/2, Zmotor)
```

左右差や前後差は`motor_overrides`で個別に上書きする。

## 9. 寸法未確定時の扱い

実測値を得る前でも、写真上の比率だけで正規化Blockoutを作れる。その場合は
対角モーター中心間距離を一時的に`100.0 mm`として比率を作り、次を明示する。

- 実寸未確定
- 質量・慣性未確定
- 物理シミュレーション利用禁止
- 外形比較専用

後で実測基準値を設定すると、全体を一様拡大するのではなく、各部品寸法をmm設定から
再計算する。これにより、厚さやクリアランスも意図した値へ更新できる。

## 10. 追加撮影を行う場合の推奨条件

- 機体と同じ平面に定規または方眼紙を置く。
- 望遠寄りで離れて撮り、透視変形を小さくする。
- カメラを機体の各面へ正対させる。
- 上下左右の余白を十分に取る。
- 6面でズーム倍率を固定する。
- プロペラを同じ角度へそろえる。
- レンズ情報を残した元画像を保存する。

追加撮影は必須ではないが、側面厚さとガード高さの精度を上げる効果が大きい。
