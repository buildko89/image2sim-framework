## 2. 採用モデルの提案：『1903704_FBX 猫モデル統合ルート』

最も品質が高く、ゲームエンジン（Godot）での動作に適しているアセットとして、**`uploads_files_1903704_FBX` の猫モデル群**を採用することを強く推奨します。

### 採用理由：
1. **猫専用の骨格と適度なポリゴン数:**
   - 形状が最初から完璧に「猫」であり、キツネから変形する際のような骨格的な違和感が最初から存在しません。
   - ボーン数が「54」とゲームエンジンに最適で軽量です。
2. **目的のモーションの網羅性:**
   - 以下の通り、ユーザー様が望む「動く（歩く、寝るなど）」に必要なアニメーションがファイルごとに分かれて揃っています。
     - `houseCat_anim.fbx` / `House_cat.fbx` : 基本の立ちポーズ、歩行動作（Walk）
     - `LazyCat_anim.fbx` / `Lazy_cat.fbx` : 寝転がる、丸くなって休む動作（Sleep / Lie-down）
     - `Shustruj_anim.fbx` / `Shustruj_animation.fbx` : 走る、素早い移動動作（Run）
     - `modnica_anim.fbx` / `Modn_cat.fbx` : その他の動作（立ち止まりや毛繕いなど）
   - これらはボーン構造が共通しているため、Blender上で簡単に「1つのモデルに複数のアニメーションを統合」することができます。

## 3. 次タスク（Task 71）以降の具体的な進め方

統合ルートを採用する場合、以下の手順で開発を推進します。

### 【Task 71】アセット統合と猫ベースモデルの構築
1. **アニメーションの統合:**
   `uploads_files_1903704_FBX` の各FBXから、歩行・走る・寝るなどのアクション（Animation Clip）をインポートし、1つのマスターBlendファイルにアクションライブラリとして統合します。
2. **モデル形状の調整（実写真へのフィッティング）:**
   - 実写真（長毛・短足）に合わせるため、リグを維持したまま、Blenderで足のボーンとメッシュを縮めます（短足化）。
   - 体を幅広にし、顔を丸くし、長毛種のふんわり感を出すため、外側に「皮毛シェル（fur shell）」やヘアカードメッシュを配置します。

### 【Task 72】UV展開の最適化と三毛猫テクスチャの作成
1. **UVの統合と整理:**
   統合したメッシュのUVマップを整理し、テクスチャが歪みなく貼れるようにします。
2. **三毛パターンペイントと質感のブレンド:**
   - カメラ投影ベイクのような自動処理の歪みに頼るのではなく、写真の模様（白いお腹、背中の黒茶のブチ、顔の左右の柄分け）を反映したベースカラーテクスチャをBlenderの3Dペイントや外部画像編集で綺麗に作成します。
   - TripoやHunyuan3Dが生成した高品質なテクスチャから毛並みのバンプマップ（凹凸情報）を抽出し、ベースカラーと合成して、ローポリながらも立体的な毛流れを表現します。

### 【Task 73】Godotでのアニメーション検証
1. **アニメーション付きGLBの出力:**
   統合したアニメーション（Walk, Run, Sleep, Idle）を含めてGLB形式で出力します。
2. **Godotレビューシーンの更新:**
   `MainAppearance.tscn` に取り込み、キー操作で各アニメーション（特に眠る動作など）が美しく切り替わることを確認します。
