## 1. 形: 測り方を変えたら結論が逆になった

### 誤っていた測り方

P3-2 では「両目の間隔で正規化した頭の横幅」を写真とモデルで比べた。これは成立しない。

- 写真で測れるのは **毛の輪郭**、モデルで測れるのは **地肌の輪郭**。
- 「顎の幅」として測っていたのは、実際には **胸の襟毛** だった。

その結果「顎を広げよ」と読み違え、`HEAD_WIDTH_PROFILE` の顎を 1.15 まで太らせた。
これがモデルの顔を樽型のボールにしていた。

### 正しい測り方: 目の高さの幅で割った「先細り比」

同一画像の中で幅どうしの比を取れば、毛か地肌かも、撮影距離も、目の間隔も効かない。

| 高さ（目の高さ基準） | 写真平均 | モデル(P3-2) | 補正 |
|---|---|---|---|
| 耳の付け根 (−0.53 IO) | 0.758 | 0.846 | 0.896 |
| こめかみ (−0.35 IO) | 0.864 | 0.912 | 0.947 |
| **目 (0)** | 1.000 | 1.000 | 1.000 |
| 顎 (+0.85 IO) | 0.858 | 1.059 | 0.810 |

IO = 瞳孔間距離。写真は face2 の正面2枚の平均。

**モデルは上も下も太い樽型。写真は目の高さ（頬骨）が最も広く、上下へ細る。**
ユーザーの言う「毛による左右の膨らみ」は、この目の高さのピークのことだった。

新しい `HEAD_WIDTH_PROFILE`（Blender の高さ z → 横幅の倍率）:

```
(0.168, 0.91)   顎
(0.182, 0.90)
(0.196, 0.96)
(0.206, 1.015)  目・頬骨 ← 膨らみのピーク
(0.218, 0.935)
(0.230, 0.865)
(0.240, 0.84)
(0.252, 0.81)   頭頂・耳の付け根
```

適用後の実測比: 耳の付け根 0.764 / 目 1.000（目標 0.758 / 1.000）。

### 耳を潰さないための平行移動

頭頂を 0.81 倍に締めると、倍率をそのまま掛ければ耳の板まで薄くなる
（P3-2 で 0.85 にしたとき耳が潰れ、0.92 まで戻した経緯がある）。

`EAR_BASE_Z = 0.252` より上では倍率ではなく **平行移動** に切り替えた。
付け根ちょうどでは `|x| = ear_x` なので `x·s == x − (1−s)·ear_x` となり、両者は連続につながる。
耳は大きさを保ったまま内側へ寄る。

### マズル

`MUZZLE_EXTEND` 0.013 → 0.017 m、`MUZZLE_NARROW` 0.08 → 0.05。
横顔写真のマズルは先が尖らず鈍いので、細める量を減らした。

鼻先が目より前に出る量 / 頭の高さ:

| | 比 |
|---|---|
| 素材（マンチカン） | 0.207 |
| P3-3 | 0.354 |
| 写真（001965 横顔） | 約 0.315 |

## 2. 骨フィットを壊していたのはマズルだった（機械ゲートが拾った）

頭を整形した直後、`qa_skin_stretch` の Jump が **0.489% → 0.537%**（閾値 0.5%）で FAIL。
`qa_locate_tears` で場所を出すと、裂けた 213 頂点は **胸・脇の下と尾根元** で、頭には 1 つも無い。

原因は `normalize_mesh` が体長を **「鼻先 → 尻尾の付け根」** で定義していたこと。
マズルを 4mm 伸ばすと体長が伸び、全身が縮み、`fit_bones` の区分線形ワープが動き、
全身のバインドが変わっていた。

→ `shape_head()` を `fit_bones()` の **後** に移し、後段の再正規化を削除した。
頭の整形は見た目だけの話で、体のバインドに影響してはならない。

（`SMOOTH_REPEAT` を 18→22 に上げる案も試したが 134→133 辺と無意味だったので戻した。
 ウェイト平滑化の問題ではなかった。）

## 3. 胸が裂けていた本当の理由

上記の順序修正でも Jump は 0.525% で FAIL のまま。裂けた頂点の支配ボーンは

```
bip01_l_forearm 49 / bone016 44 / bip01_r_forearm 28 / koha_belly_mid 21 ...
```

前脚が過半。P3-2 で `place_leg_chains()` が脚の付け根を **足先の真上**（|X|≈0.040）へ出していた。
胴の半幅が 0.05 なので、肩の骨が胸壁の内側ぎりぎりに立つ。
Jump で腕が振れると胸の正中線が剪断される。

付け根を外へ出したのは「腹の頂点を脚ボーンに取られないため」だったが、
その役目は今や `koha_belly_*` ボーンが担っている。そこまで出す必要はもう無い。

→ `ROOT_X_FRAC = 0.65`（足先の |X| に対する割合）を導入。

| | Jump 破綻辺 | 腹→脚ウェイト |
|---|---|---|
| 付け根 = 足先の真上 | 0.525% FAIL | 41.7% |
| 付け根 = 足先の 0.65 | **0.481% PASS** | **42.7%** |

腹はほぼ悪化していない。**トレードオフではなく、単に出しすぎていた。**

## 4. 配色: 俯瞰写真から読み直した

俯瞰 `1648713873399_frame_002490.jpg` と正面2枚から読めた配置:

- 白いブレーズが鼻から額を通り頭頂まで一続き。マズル・頬・顎はすべて白。
- ジンジャーは **両眉〜こめかみ** に広く乗る。
- 暗色は顔の **外側（目より後ろ・耳の下）** にだけ回り込む。頬の真ん中には無い。
- 黒は **頭頂を横切る帯**。白いブレーズが中央でそれを左右に割る。
- 猫の左（+X）のマズル、鼻のすぐ脇に橙のそばかす。

### 途中で分かったこと: 耳は左右で UV を共有している

`+X` 側の耳に置いた斑が実効面積 0.00% になった。ベイクした mask を見ると
Y > 0.256 の `+X` 側にテクセルが 1 つも無い。

GLB の UV を直接調べると、左右の耳の UV bbox はほぼ一致し、
鏡像対応点の UV 距離の中央値は **0.0046**（顔全体は 0.103）。
**耳の板だけは同じ UV 島を使う。** ベイクは後勝ちなので `-X` 側の座標だけが残る。

→ 耳の斑は `-X` の座標で 1 つ置けば両耳に乗る。耳を左右非対称にすることはできない。

同様に `+X` 側の頭頂は Y=0.250 で X ≤ 0.0305 までしか面が無いので、
黒帯を ±対称に置くと外れる。左は内側へ寄せた。

### 目の位置

素材テクスチャの虹彩（黄緑）の重心をベイク経由で 3D に落として実測し直した。

```
右 (-0.0134, 0.2154, 0.1882)   左 (+0.0169, 0.2143, 0.1883)   瞳孔間 0.030
```

## 6. 残る差

- **頭が体に対して小さい。** 写真の koha は顔がもっと大きく見える。素材の比率のまま。
- **耳が低く、間隔が狭い。** 耳の板は Y 0.252〜0.270（高さ 18mm）しかない。
  そのため頭頂の黒帯を置く面がほとんど無く、黒はほぼ耳の付け根に乗っている。
- 耳を左右非対称にできない（UV 共有）。
- 胸・首の襟毛（写真では巨大）がモデルには無い。
- 目のアイライン（細い黒い縁）は素材のまぶたの陰影で代用している。

## 7. 教訓

- **写真とモデルで「同じもの」を測っているか、毎回疑うこと。**
  毛の輪郭と地肌の輪郭、顎と襟毛。P3-2 の顎の広げすぎはこれで起きた。
  同一画像内の比を取れば、この種の取り違えは起きにくい。
- **見た目のための変形が、体のバインドを壊す経路が無いか確認すること。**
  `normalize_mesh` が鼻先を基準にしていたせいで、マズル 4mm がゲートを割った。
- **機械ゲートは、変えた場所ではなく壊れた場所を教えてくれる。**
  `qa_locate_tears` が「裂けたのは頭ではなく胸だ」と即答したので、
  頭の整形を疑うのをやめて骨フィットを疑えた。
