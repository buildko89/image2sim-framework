# ドローンシミュレータ向け：猫アニメーション・ユースケース再検討レポート

ユーザー様からご提示いただいた具体的なユースケース（「寝ている状態からスタート」「ドローン接近時に威嚇・ネコパンチをする」「逃げる」というドローン操縦者向けのゲーム要素）を踏まえ、最適なアプローチを再検討しました。

---

## 1. 必要なモーションとアセットの現状

ゲームサイクルで必要となるアクションは以下の通りです。

1. **初期状態:** 睡眠（丸まって眠る / 伏せて寝る）
2. **トリガー（ドローン接近）:** 起き上がる・警戒する・威嚇する
3. **攻撃（ドローン至近）:** ネコパンチ（前足での打撃）
4. **回避・移動:** 逃げる（走る・跳ぶ）

### 提供アセットが持つアニメーションの比較

- **`uploads_files_1903704_FBX`（猫モデルパック）：**
  - **持っている動き:** `houseCat`（歩行）、`LazyCat`（眠る・丸くなる）、`Shustruj`（走る / 逃げる動作に最適）、`modnica`（佇む / 待機）
  - **不足している動き:** ネコパンチ、威嚇、起き上がる遷移
- **`uploads_files_5119404_White+Tiger.blend`（トラ）：**
  - **持っている動き:** 睡眠（Lie Prone）、起き上がる（遷移）、威嚇（Howl）、攻撃（Attack / ネコパンチに該当）、走る（Run）、跳ぶなど195種類

## 2. 実現のための3つのアプローチ案

### 【案A】『1903704_FBX』を軸に、不足アクションを Blender で新規作成する（推奨 🌟）
- **手法:** 基本体型や「歩く・走る・眠る」といった基本動作は `1903704_FBX` を使用。不足している「ネコパンチ（打撃）」および「威嚇・起き上がる」モーションのみを、Blender上でこのモデルに手動でキーフレームを設定して作成します。
- **メリット:**
  - **圧倒的な猫らしさ:** 短い手足を一生懸命伸ばしてドローンを叩く、飼い猫特有のコミカルで可愛らしい「ネコパンチ」を手動で完全に制御・表現できます。
  - **安全な変形:** 短足・長毛へのカスタマイズ（Task 71）を行っても、アニメーション作成時にその体型を前提とするため、骨のめり込みや破綻が一切起きません。
  - **軽量:** 54ボーンというシンプルな構造で、Godotでの動作が非常に軽快です。
- **デメリット:**
  - ネコパンチや起き上がりモーションをBlenderで新規に作成（モデリング・アニメーション制作）する作業コストが発生します。

### 【案B】『1903704_FBX』のメッシュに、トラ（Tiger）のアニメーションを「リターゲティング」する
- **手法:** 見た目は `1903704_FBX` の猫メッシュと54ボーンリグを使用。トラ（120ボーンまたは38ボーン）の持つ「Attack」や「Howl」のアニメーションを、Blenderの骨格転送機能を使って猫の54ボーンへ転写（Bake）します。
- **メリット:**
  - トラのアセットが持つ野生的な攻撃動作や威嚇動作、寝起き動作をそのまま流用できます。
- **デメリット:**
  - **体型の破綻リスク:** 手足の長いトラのモーションを短足猫に転写するため、前足が地面に突き刺さったり、パンチ時に腕が異常に引き伸ばされたりする現象が起きやすく、Blenderでの手動修正（クリーンアップ）にかなりの手間がかかります。

### 【案C】トラ（Tiger）の骨格をベースにし、猫のメッシュをアタッチする
- **手法:** `White+Tiger.blend` のリグ（スケルトン）をそのままベースとして使用し、メッシュのみを `1903704_FBX` などの猫メッシュに差し替え、短足化の変形を加えます。
- **メリット:**
  - 195個のアニメーションをそのまま（リターゲティングなしで）即座に適用できます。
- **デメリット:**
  - 元がトラ（大型猫科）の骨格なので、足を極端に短くした際に、歩行や走りなどの接地モーションがすべて浮いてしまう可能性が高く、全アニメーションの調整が必要になります。
  - リグが120ボーンと複雑すぎるため、Godot等のゲームエンジンでの動作やプログラム制御が重くなります。

## 3. Geminiとしての推奨プラン：【案A】（新規作成・追加ルート）

今回のゲームコンセプトである **「ドローンを警戒し、ネコパンチで撃退しようとする飼い猫」** というコミカルでインタラクティブな要素を考えると、**【案A：1903704_FBXベース ＋ パンチ等の手動追加】** が最も品質が高く仕上がります。

### 理由：
1. **「短足猫のネコパンチ」はトラのパンチとは異なる:**
   トラの「Attack」は獲物を仕留める鋭いスワイプですが、ゲームで操縦者が楽しむ「ネコパンチ」は、短い前足でドローンをペシペシと叩くような、飼い猫特有の愛らしい動きが求められます。これは手動でキーフレームを打ったほうが、はるかにコンセプトに合致した魅力的な動きになります。
2. **必要な追加アクション数が少ない:**
   「眠る（Lazy）」「走る（Shustruj）」「歩く（houseCat）」という最も制作が難しい全身移動のループアニメーションはすでにアセットに入っています。
   追加で手付け作成が必要なのは、**「ネコパンチ（1アクション）」** と **「起き上がる/威嚇（1〜2アクション）」** のみであり、Blenderでの作業量としても現実的（数時間〜1日程度）です。

### 今後の具体的なマイルストーン（案A採用時）
- **Task 71:** `1903704_FBX` のアニメーション（歩・走・眠・佇）の統合 ＆ 短足・長毛への形状調整。
- **Task 71.5:** 統合モデルに対して、Blenderで「ネコパンチ」および「威嚇・起き上がり」モーションを手動で作成・追加。
- **Task 72:** UV展開と三毛猫テクスチャの作成。
- **Task 73:** Godotに全モーション（睡眠、パンチ、逃走等）が入ったGLBを持ち込み、ドローンの接近に応じたモーション遷移（AnimationTree等）を実装・検証。
